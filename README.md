# TinyFLVER
<img src="https://i.postimg.cc/VL6t82Z1/Screenshot.png"/>
<br>
- Since TinyFLVER expects textures to be in the same folder as .flver, and WitchyBND unpacks them in .tpf folder, added basic unpacking for .partsbnd.dcx and .tpf.dcx files based on Yabber. Only for BND4 (DS3+) files. It is not a replacement for WitchyBND and should be used alongside it. Also it can repack back all textures in folder without the need to manually add them in .xml file. To unpack open .dcx file with TinyFLVER. To repack open _.yab.<br>
- DDS thumbnails based on RenderDoc.dll. To install run "DDS Thumbnails.cmd".<br>
- Expect bugs, especially on import. It is primarily a viewer, and import is expected to be made with other tools. But still, I hope I will be able to improve import next.<br>
